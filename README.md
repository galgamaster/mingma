# 明码 · 这个价贵不贵

把一次报价放进当地价格分布里，看它落在第几百分位。贵不贵不是绝对值，是分位数。

## 一句话

输入你买的东西、在哪买的、花了多少钱，明码会告诉你这个价在当地属于「便宜 / 正常 / 偏贵」，并给出 P10 / P50 / P90 三档参考价，以及「这一单比中位数多花了多少」。

## 运行

直接双击 `index.html` 可以在浏览器打开，但定位功能需要 `http(s)` 环境。推荐任选其一部署后访问：

- GitHub Pages：把本目录推到仓库的 `gh-pages` / `main` 分支并开启 Pages
- Vercel / Netlify：导入本目录即可

部署后把网址生成二维码，评委手机扫码即可直接体验。

## 功能

- 8 个内置品类 + 自定义品类（存 localStorage）
- 42 个城市、4 类渠道的价格指数
- 对数正态分布分位数计算（erf 近似 + 二分求 ppf）
- 设备定位优先、IP 定位多源投票兜底
- 账单持久化、分享卡生成、离线缓存（Service Worker）

## 数据说明

当前价格数据为**演示用示例数据**：各品类的基准价与波动值、各城市的价格指数为模拟值，仅用于展示「分位数」这个判断方法。正式使用时建议接入公开市场价格数据源（如农业农村部批发市场价格、惠农网等），并标注采样时间与口径。
